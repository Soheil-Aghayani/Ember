## Shape of the crate

- Plain data: `Node`, `Subscription`, `ParsedLinks`, an error enum. Functions, not traits.
- `parse_share_link(&str) -> Result<Node, ParseError>` for vless, vmess, trojan, ss, hysteria2/hy2, wireguard,
  socks; `parse_subscription(body: &str) -> Vec<Node>` (base64, plain lists, Xray JSON, `.conf`, `.ovpn` detection,
  exactly as the Kotlin does, including odd cases).
- `xray_config(node, settings) -> serde_json::Value` producing the same JSON the Kotlin produces, field for field.
- Network (`fetch_subscription`, `test_node`, `check_site`) takes a small `Http` struct built on `ureq` + rustls; keep
  it behind functions so tests use fixtures and never touch the network.
- Dependencies allowed: `serde`, `serde_json`, `base64`, `url`, `ureq` (rustls feature), `qrcode`, `thiserror`. Ask in
  your notes before adding others. No async runtime.
- Never log or print a subscription link; log hosts only. No real links in tests (use `example.com`).
