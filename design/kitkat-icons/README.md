# Ember KitKat icon set

Editable SVG reconstructions based on the selected concept sheet.

- kitkat-icons-master.svg is the 3-by-2 contact sheet. Its six top-level groups are named layer-home, layer-servers, layer-settings, layer-logs, layer-whats-new, and layer-about; select each group in VectorCraft's Layers or Objects panel.
- The six individual SVG files use a 512 by 512 viewBox and transparent backgrounds.
- Shapes, gradients, shadows, glass reflections, and the simplified wafer pattern are native SVG elements. No raster image is embedded.
- Files use common SVG 1.1 features (groups, paths, circles, rectangles, gradients, and patterns) for VectorCraft editing and Android rendering.
- This is a clean vector reconstruction of the approved raster concept, not an automatic or pixel-exact trace. It is intended to preserve the look while keeping the geometry editable.

Open kitkat-icons-master.svg in VectorCraft to edit the full sheet. Open an individual icon SVG to edit or export a single glyph.
